# Add Todo Runtime Validation Demo

## Why

OpenSpec needs a concrete demo change that shows how runtime validation closes the loop between spec scenarios and browser evidence.

## What Changes

- Add a no-login todo application example that can be validated end-to-end
- Add runtime-validation scenarios for add / complete / delete flows
- Demonstrate `validation.md` writeback and `openspec freeze`

## Capabilities

- **New Capabilities**: `todo-validation`
- **Modified Capabilities**: none

## Impact

- Affected code: `examples/demo-todo-app/**`
- Affected docs: runtime validation walkthrough
